Debugging Instructions:

Open 2 terminals, with your virtual environment (venv) active.

Terminal 1 - Docker Engine:
    Activation (Regular Option):
        'docker-compose up --build'
    Exit:
        Ctrl + C
    Termination:
        'docker-compose down'
    Verify Active:
        http://localhost:8000/docs in your browser
    Reload with Code Changes:
        docker-compose up --build --force-recreate

Terminal 2 - Client Screens:
    Activation:
        python client/main.py
